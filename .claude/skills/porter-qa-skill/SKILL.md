### 問題 2：BOTRUN 波特人有哪些主要功能？

**回答：**

BOTRUN 波特人提供以下主要功能：

1. **知識庫建立**：可以針對 PDF、DOCX、CSV 等文件檔案進行知識庫的建立，專家可一問一答進行互動，所提供的答案有引證來源。

2. **多角色專業分工**：波特人有多個角色分別有不同專長，例如波文專門處理文件問答，波圖專門處理圖表繪製，波分專門處理數據分析和程式碼生成等等。

3. **數據整合能力**：波特人可以進行 Google Drive 資料應用、公開網站上的 PDF 連結擷取、YouTube 字幕提取。

### 問題 3：BOTRUN 波特人的核心特色是什麼？

**回答：**

BOTRUN 波特人有三個核心特色：

1. **融合地端**：透過 Docker 運用 Ollama 可以跑地端模型
2. **領域介面**：允許結合 CKEditor 以及 Google Sheet 等各種領域專業要用的 UI
3. **自動波特**：波特人可以一群人自動彼此交談（Multi-agent 架構）

此外，波特人的技術架構可透過六個層次來進行客製化的打造：
1. 第1層預訓練 Pre-training
2. 第2層微調 Fine-tuning
3. 第3層提示工程 Prompt Engineering
4. 第4層工具 Tool
5. 第5層檢索增強 RAG
6. 第6層波特人小隊 Multi-agent

**引證來源：**
- 來源網址：https://medium.com/@bohachu/雙棲波特人gpts做專案-botrun-ai做產品-融合地端-領域介面-自動波特-d0c4e3fe832d
- 引證文字：「botrun.ai有三個特色：融合地端（docker運用ollama可跑地端模型）、領域介面（允許結合CKEditor以及google sheet等各種領域專業要用的UI）、自動波特（波特人可以一群人自動彼此交談）」

**引證來源：**
- 來源網址：https://intro.botrun.ai/about.html
- 引證文字：「波特人botrun技術可透過六個層次來進行客製化的打造：第1層預訓練Pre-training、第2層微調Fine-tuning、第3層提示工程Prompt Engineering、第4層工具Tool、第5層檢索增強RAG、第6層波特人小隊Multi-agent」

### 問題 4：BOTRUN 波特人如何確保資料安全？

**回答：**

BOTRUN 波特人提供多重資料安全保障措施：

1. **封閉式地端部署**：可以在專屬機房操作，防止資料外流
2. **專屬雲端環境**：提供封閉的雲端專區，確保資料安全
3. **機敏資料保護**：波特人受過特定領域的訓練，確保能夠精確地解讀和執行專業領域的指令

### 問題 5：BOTRUN 波特人有哪些應用案例？

**回答：**

BOTRUN 波特人在多個領域都有成功的應用案例：

1. **數據分析與地圖繪製**：透過大語言模型技術，讓不會撰寫程式的資料分析師也能夠完成複雜的資料前處理、取得清洗後的檔案，甚至繪製圖表。

2. **政府應用**：中央暨相關機關創新應用組，智慧政府應用領域（環境部：物聯網與AI相遇-智慧環境監測整合方案）。

3. **環保緊急應變**：在遇到火災這種環保急事的時候，利用 Airbot 的 AI 技術，為環保人員提供一個方便快捷的平台，可以迅速掌握空氣品質、天氣情況和可能受影響的區域的即時消息。

4. **審議輔助**：透過生成式AI波特人，將多年審議經驗轉化為專家波特人，輔助分析師進行計畫書多面向審議、歷史計畫比對，提升六倍效率。

5. **SQL開發加速**：產出影響少子化根因分析SQL，產出有無自有住宅，是否影響初婚年齡SQL，產出老人概況分析SQL等等。加速開發時間，由兩天變成三小時。
